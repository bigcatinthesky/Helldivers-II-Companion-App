Helldivers II Companion App

This project is a website companion for the live service game "Helldivers 2", displaying real time live game information in a readable and searchable formart.
This is a fanmade project, not associated or endorsed by the developers in any way.
While this project is interesting from an analysis perspective, serving as a record of data for locations not currently viewable in game, its true intent is to showcase proficiency in Python development.
HTML is used but web design has not been the project's focus.
Tests are present to demonstrate functionality and test proficiency.

This project depends directly on the response, flask, flask_session, unittest, and json libraries.
It can be ran on any modern computer with a network connection, the Python language, and a compiler.

It is intended for a user to execute the code locally by running the "run_web.py" file.
Then click the link in the terminal to access the local webpage.

The "run_cli.py" file is deprecated and should not be used as it is missing some functionality.
This project is not currently suitable for mass deployment.

Created by Parker Bowman

Development has stopped for the foreseable future, but will resume in the event of significant in-game performance improvments.
