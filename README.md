## Helldivers II Companion App

This project is a website companion for the live service game "Helldivers 2", displaying real time live game information in a readable and searchable format.
Planets can be searched individually or by galactic sectors.
This is a fan-made project, not associated or endorsed by the developers in any way.

It can be ran on any computer with a network connection and the Python language. All dependencies are listed in the requirments.txt file.
+ To run the CLI application run the run_cli.py file.
+ To run the web app run the run_web.py file.
